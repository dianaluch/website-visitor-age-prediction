## Модель предсказания возрастной категории пользователей сайтов
```
Цель - построить модель многоклассовой классификации, которая определяет возрастную категории
пользователя по истории посещения сайтов, времени активности,интересам, рекламному поведению и другим характеристикам.
```

### Постановка задачи

- **Тип задачи:** многоклассовая классификация (5 классов)
- **Метрики:** F1-macro, Precision-macro, Recall-macro
- **Целевой показатель:** F1-macro ≥ 0.75 на тестовой выборке
- **Целевая переменная:** `age_category`:

  | Класс | Возрастная категория |
  |:---:|---|
  | 0 | Младше 18 лет |
  | 1 | 18–25 лет |
  | 2 | 26–40 лет |
  | 3 | 41–55 лет |
  | 4 | 56 лет и старше |

### Датасет
Исходные данные представлены шестью файлами, которые в последующем объединены в датасет из 5 826 пользователей и 37 признаков:
1. `ds_s13_users.csv`  - идентификаторы пользователей и целевая переменная;
2. `ds_s13_visits.csv` - история посещений сайтов;
3.  `ads_activity.csv` - характеристики рекламной активности пользователей;
4. `surf_depth.csv`  - глубина просмотра сайтов;
5. `primary_device.csv` - устройства пользователя;
6. `cloud_usage.csv` - информация об использовании облачных сервисов.

### Модели

В рамках проекта проведено сравнение следующих алгоритмов:

| Модель                     | Назначение                                                                      |
|----------------------------|---------------------------------------------------------------------------------|
| `LogisticRegression`       | Линейная модель многоклассовой классификации                                    |
| `SVC (linear, RBF, poly)`  | Классификация с тремя типами ядер: линейное, радиально-базисное, полиномиальное |
| `OneVsRestClassifier(SVC)` | One-vs-Rest стратегия многоклассовой классификации                              |

Для оценки моделей использовалась стратифицированная кросс-валидация (`StratifiedKFold`). 
Подбор гиперпараметров выполнялся с помощью `GridSearchCV`.


### Отбор признаков

Для повышения качества классификации и уменьшения размерности признакового пространства исследованы несколько подходов:

 - **Phik-корреляция** - отбор признаков по силе связи с целевой переменной. Метод реализован с помощью собственного трансформера `CorrelationSelector`, интегрированного в Pipeline;
 - **RFE** - рекурсивное исключение признаков на основе важности;
 - **SFS** - последовательный отбор признаков по качеству модели.

### Итоговые результаты

В качестве лучшей финальной модели выбрана модель **SVC с RBF-ядром, стратегией One-vs-Rest и корреляционным отбором признаков**.

| Метрика |  CV   | Test  |
|---|:-----:|:-----:|
| F1-macro | 0.904 | 0.898 |
| Precision-macro | 0.914 | 0.893 |
| Recall-macro | 0.897 | 0.904 |

Итоговая модель превысила установленный целевой порог качества и продемонстрировала стабильные результаты на независимых данных.
Небольшая разница между результатами кросс-валидации и тестирования свидетельствует об устойчивости качества модели. При этом класс 
`18–25 лет` остаётся наиболее сложным для классификации.
